C4BG013GP0Dépose - repose : Volet arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
outil Référence Désignation
Figure : e5ag02mt
 [1350-ZZ] Outils de dégarnissage
2. Opérations préliminaires
Ouvrir le volet arrière .
Débrancher la batterie .
Déposer :
  • La tablette arrière (/)
  • Les garnitures de custode
  • Les garnitures d’aile arrière
3. Dépose
Figure : c4bg0bdd
Déposer vis (1).
Déconnecter le connecteur ( en "a" ).
Déclipper : Le faisceau électrique (3) ( en "b" ) ; À l’aide de l’outil [1350-ZZ].
Dégager : Le faisceau électrique (3).
Déclipper : Le passe-gaine d’étanchéité ( 2) ; À l’aide de l’outil [1350-ZZ].
Dégager le faisceau électrique (3).
Figure : c4bg0bed
Déclipper : Le tuyau de lave-vitre (5) ( en "c" ) ; À l’aide de l’outil [1350-ZZ].
Désaccoupler : Le tuyau de lave-vitre (5) ( en "d" ) .
Déclipper : Le passe-gaine d’étanchéité ( 4) ; À l’aide de l’outil [1350-ZZ].
Dégager : Le tuyau de lave-vitre (5).
Figure : c4bg0bfd
NOTA : 2 personnes sont nécessaires pour effectuer les opérations suivantes.
Déclipper les vérins de volet (7) ( en "e" ) ; À l’aide d’un tournevis plat.
Déposer :
  • Les vis (8)
  • Le volet arrière (6)
4. Repose
Procéder dans l’ordre inverse des opérations de dépose.
Rebrancher la batterie.
5. Réglage
Fermer le volet arrière ( 6).
Régler jeux et affleurements ; À l’aide des vis (8).
Si nécessaire : Le réglage du volet peut être complété par le réglage de la gâche du volet arrière .
Ouvrir le volet arrière .
Serrer les vis (8) à 1,5 m.daN .
Procéder dans l’ordre inverse des opérations de dépose.
Vérifier l’étanchéité des passe-gaines (2, 4).
Vérifier le fonctionnement des équipements.
