2. Dépose
Placer le véhicule sur un pont élévateur à 2 colonnes.
Déposer les roues avant.
2.1. Côté conducteur
Figure : c5jg04sd
Déclipper les agrafes (en "a") ; À l’aide de l’outil [1350-ZZ].
Déposer :
  • Les vis (2)
  • Le pare-boue (1)
2.2. Côté passager
Figure : c4ag1jkd
Déclipper les agrafes (en "b") ; À l’aide de l’outil [1350-ZZ].
Déposer :
  • Les vis (3), (5)
  • Le pare-boue (4)
3. Repose
Procéder dans l’ordre inverse des opérations de dépose.
Serrer les vis (2), (3), (5) à 0,8 m.daN .
Serrer les vis de roues .
NOTA : Vérifier l’état des agrafes de fixation ; Remplacer si nécessaire.
