C4EB012SP0Identification : Produit amortissant projeté
1. Présentation
Ce véhicule est équipé des produits amortissants suivants afin de réduire et limiter les vibrations ressenties :
  • Produit amortissant projeté
  • Produit amortissant projeté trifonction
Les produits amortissants projetés remplacent les plaques amortissantes bitumées ou les plaques insonorisantes feuille fusible (IFF).
1.1. Produit amortissant projeté
Ce produit assure les fonctions suivantes :
  • Étanchéité (air et eau)
  • Acoustique (amortissant vibratoire) sous forte épaisseur
1.2. Produit amortissant projeté trifonction
Ce produit assure les fonctions suivantes :
  • Antigravillonnage
  • Étanchéité (air et eau)
  • Acoustique (amortissant vibratoire) sous forte épaisseur
NOTA : Le produit trifonction est appliqué en usine par pulvérisation.

3. Remplacement
3.1. Produit amortissant projeté
L’échange d’un élément enduit d’un produit amortissant projeté nécessite la pose de l’un des produits suivants (Produits recommandés par le constructeur ) :
  • Produit amortissant projeté
  • Plaques amortissantes bitumeuses (À découper par le réparateur )
ATTENTION : Utiliser les produits recommandés par le constructeur (Ingrédients recommandés : Carrosserie ).
3.2. Produit amortissant projeté trifonction
Figure : c4eb017d
L’échange d’un élément enduit d’un produit amortissant projeté trifonction nécessite la pose des produits suivants (Produits recommandés par le constructeur ) :
  • Plaques amortissantes bitumeuses  (en " b") (Côté intérieur du véhicule )
  • Antigravillonnage  (en " c") (Côté extérieur du véhicule )
NOTA : Le brouillard du produit d’antigravillonnage est admis au-delà des zones précisées, excepté les zones sans antigravillonnage et les limites de style.
