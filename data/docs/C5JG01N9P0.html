C5JG01N9P0Dépose - repose : Pare-chocs arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Opérations préliminaires
Effectuer les opérations suivantes :
  • Ouvrir le volet arrière
  • Mettre le véhicule sur un pont élévateur deux colonnes
Déposer :
  • Les pare-boue arrière (Partiellement)
  • Les feux arrière
2. Dépose
2.1. Pare-chocs arrière
Figure : c5jg05yd
NOTA : Opérations symétriques.
Desserrer les vis (1) sans les déposer.
Dégager le pare-chocs arrière (2) (Suivant les flèches ).
Déclipper le pare-chocs arrière (2) en "a".
Figure : c5jg05zd
Déconnecter le connecteur (en "b").
Déposer :
  • Les agrafes  (en "c")
  • Le pare-chocs arrière (2)
2.2. Supports de pare-chocs arrière
Figure : c5jg060d
Déposer :
  • Les vis (3)
  • Le support de pare-chocs arrière (4)
Figure : c5jg061d
NOTA : Opérations symétriques.
Déposer :
  • Les vis (1)
  • Le support de pare-chocs arrière (5)
Chasser les clous de rivets avant le perçage.
Percer les têtes de rivets (7) à l’aide d’un foret Ø 6 mm.
Déposer : Le support de pare-chocs arrière (6).
Percer les corps de rivets restants.
3. Repose
Procéder dans l’ordre inverse des opérations de dépose.
Effectuer le réglage des jeux et affleurements .
Serrer : Les vis (1, 3) à 1 m.daN.
Vérifier le fonctionnement des différents équipements.
