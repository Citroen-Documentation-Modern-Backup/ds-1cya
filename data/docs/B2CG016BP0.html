IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
outil Référence Désignation
Figure : e5ab0fmt
 [1617-J] Bouchons d’étanchéité
2. Dépose
Mettre le véhicule sur un pont élévateur.
Positionner le levier de sélection de vitesses au point mort.
Débrancher la batterie .
Déposer :
  • Le résonateur d’air (Motorisation EP6)
  • Le conduit d’admission d’air (Motorisation DV6)
  • La protection sous moteur (Si nécessaire)
Figure : b2cg08qd
Pincer les languettes des 2 rotules (1) (en "a") ; À l’aide d’une pince à becs.
Désaccoupler les 2 rotules (1).
Désaccoupler la canalisation hydraulique (2) ; Tirer sur l’agrafe (3).
NOTA : Prévoir l’écoulement du liquide de frein.
Dégrafer : La canalisation hydraulique (2) (en "b").
Obturer la canalisation hydraulique (2) ; À l’aide de bouchons de propreté [1617-J].
2.1. Moteur EP
Figure : b2cg08vd
Dégrafer : La durit de refroidissement (en "c").
Déposer les vis (4).
Écarter : La pompe à eau électrique de refroidissement turbocompresseur (5).
2.2. Véhicule non équipé du système "Stop and Start"
Figure : b2cg0crd
Déconnecter le connecteur  (en "d").
Dégrafer le faisceau électrique  (en "e").
Déposer :
  • L’agrafe (7)
  • Le raccord purgeur (8)
Obturer la canalisation hydraulique ; À l’aide de bouchons de propreté [1617-J].
Déposer :
  • Les 4 vis (6)
  • Le module de commande de vitesses
ATTENTION : Veiller à la propreté en évitant toute chute de corps étranger dans la boîte de vitesses.
2.3. Véhicule équipé du système "Stop and Start"
Figure : b2cg2gxd
Déconnecter les connecteurs  (en "h").
Dégrafer le faisceau électrique  (en "g").
Déposer :
  • L’agrafe  (en "f")
  • Le raccord purgeur (10)
Obturer la canalisation hydraulique ; À l’aide de bouchons de propreté [1617-J].
Déposer :
  • Les 4 vis (9)
  • Le module de commande de vitesses
ATTENTION : Veiller à la propreté en évitant toute chute de corps étranger dans la boîte de vitesses.
3. Repose
ATTENTION : Régler les câbles de commande à chaque dépose du module de commande de vitesses.
ATTENTION : Respecter les couples de serrage .
Figure : b2cg2gyd
NOTA : Les surfaces d’étanchéité du module de commande de vitesses doivent être parfaitement propres.
NOTA : Remplacer systématiquement le joint d’étanchéité (11).
ATTENTION : Avant d’effectuer la repose du module, vérifier le bon alignement des doigts de passage (13) du module et contrôler le bon alignement des crosses de fourchettes (12) (Suivant l’axe ).
Reposer :
  • Le joint d’étanchéité (11) (neuf)
  • Le module de commande de vitesses sur les 2 goupilles (en "j")
3.1. Véhicule équipé du système "Stop and Start"
Reposer les 4 vis (9).
NOTA : Serrer les 4 vis (9) en "croix".
Enlever les bouchons de propreté [1617-J].
Reposer :
  • Le raccord purgeur (10)
  • L’agrafe  (en "f")
Connecter les connecteurs  (en "h").
Agrafer le faisceau électrique  (en "g").
3.2. Véhicule non équipé du système "Stop and Start"
Reposer les 4 vis (6).
NOTA : Serrer les 4 vis (6) en "croix".
Enlever les bouchons de propreté [1617-J].
Reposer :
  • Le raccord purgeur (8)
  • L’agrafe (7)
Connecter le connecteur  (en "d").
Agrafer le faisceau électrique  (en "e").
3.3. Moteur EP
Mettre en place : La pompe à eau électrique de refroidissement turbocompresseur (5).
Reposer les vis (4).
Agrafer : La durit de refroidissement (en "c").
3.4. Repose (suite)
Enlever les bouchons de propreté [1617-J].
Accoupler : La canalisation hydraulique (2).
Agrafer : La canalisation hydraulique (2) (en "b").
Clipper la canalisation hydraulique (2) en appuyant sur l’agrafe (3).
Accoupler les 2 rotules (1).
Déposer la console centrale .
BVM MC ET BVM6
Effectuer le réglage des commandes de boîte de vitesses .
Effectuer la purge du circuit hydraulique d’embrayage .
Reposer :
  • La console centrale
  • Le conduit d’admission d’air (Motorisation DV6)
  • Le résonateur d’air (Motorisation EP6)
  • La protection sous moteur (Si nécessaire)
Reposer le véhicule sur ses roues.
Vérifier que le passage de toutes les vitesses s’effectue sans "point dur".
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Rebrancher la batterie.
