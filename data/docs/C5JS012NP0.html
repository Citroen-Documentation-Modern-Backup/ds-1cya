4. Déshabillage
Déposer la plaque de police .
4.1. Déflecteurs de pare-chocs avant
Figure : c5js08bd
Chasser les clous de rivets avant le perçage.
Percer les têtes de rivets (12) ; À l’aide d’un foret Ø 6 mm.
Déclipper les déflecteurs de pare-chocs avant (6) (en "a") ; À l’aide de l’outil [1350-ZZ].
Déposer les déflecteurs de pare-chocs avant (6).
Percer les corps de rivets restants.
4.2. Absorbeur de chocs
Figure : c5js01xd
Déclipper : L’absorbeur de chocs (1) (en "b") ; À l’aide de l’outil [1350-ZZ].
Déposer : L’absorbeur de chocs (1).
4.3. Grille de pare-chocs (avant)
Figure : c5js08gd
Araser les points de fixation de la grille de pare-chocs avant (10) (en "d").
Déclipper : La grille de pare-chocs avant (10) (en "c") ; À l’aide de l’outil [1350-ZZ].
Déposer : La grille de pare-chocs avant (10).
Figure : c5js08kp
Déposer les vis (13).
Déclipper l’obturateur (5) (en "e") ; À l’aide de l’outil [1350-ZZ].
Déposer l’obturateur (5).
Figure : c5js08sd
Déclipper la trappe d’accès (7) ; À l’aide de l’outil [1350-ZZ].
Déposer la trappe d’accès (7).
Figure : c5js08vd
Déclipper : Le bandeau central (8) (en "f") ; À l’aide de l’outil [1350-ZZ].
Déposer : Le bandeau central (8).
4.4. Emblème de la marque
Figure : c5js08yd
Déclipper : L’emblème de la marque (9) (en "g") ; À l’aide de l’outil [1350-ZZ].
Déposer l’emblème de marque (9).
4.5. Supports (Feux de brouillard)
Figure : c5js091d
Araser les points de fixation  (en "j").
Déclipper : Les supports de feu de brouillard (3) (en "h") ; À l’aide de l’outil [1350-ZZ].
Déposer : Les supports de feu de brouillard (3).
4.6. Supports (Feux diurnes) (Suivant équipement)
Figure : c5js094d
Araser les points de fixation  (en "k").
Déclipper : Les supports de feu diurne (4) (en "l") ; À l’aide de l’outil [1350-ZZ].
Déposer : Les supports de feu diurne (4).
5. Habillage
Procéder dans l’ordre inverse des opérations de déshabillage.
IMPERATIF : Utiliser la mallette de réparation soudage plastique et bouterollage (Voir catalogue équipement des marques).
Bouteroller les points de fixation arasés.
Reposer :
  • Les feux diurnes (Suivant équipement)
  • Les feux de brouillard avant
  • Le pare-chocs avant
Rebrancher la batterie.
Vérifier le fonctionnement des différents équipements.
