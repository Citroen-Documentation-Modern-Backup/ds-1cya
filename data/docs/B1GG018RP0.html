B1GG018RP0Dépose - repose : Radiateur de refroidissement moteur
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Vidanger le circuit de refroidissement.
Débrancher la batterie de servitude.
Figure : b1bg4e4d
Déposer :
  • L’agrafe (5)
  • Le résonateur d’air (4)
  • Le raccord d’air (3)
Désaccoupler la durit (2) (en "a").
Déposer les vis (1).
Déplacer le support moteur-boîte de vitesses vers l’arrière (suivant flèche ).
Figure : b1gg0fwd
Déconnecter les connecteurs :
  • Résistance motoventilateur (en "e")
  • Relais motoventilateur (en "b")
  • Motoventilateur  (en "d")
Déclipper le faisceau électrique .
NOTA : Protéger le radiateur de refroidissement.
Déposer les vis (6).
Soulever l’ensemble motoventilateur (7) pour dégager les 2 fixations inférieures (en "c").
Figure : b1bg14xd
Désaccoupler et écarter le tube de dégazage (8).
Déconnecter le connecteur (9).
Déposer les vis (11).
Déclipper les fixations du radiateur de refroidissement moteur (10) (en "g").
Soulever le radiateur de refroidissement (10) pour dégager ses 2 fixations inférieures (en "f").
Déposer le radiateur de refroidissement (10) (par le dessous du véhicule).
2. Repose
NOTA : Vérifier la présence des silentblocs pour la fixation du radiateur de refroidissement moteur (10).
Reposer le radiateur de refroidissement (10).
Clipper les fixations supérieures du radiateur de refroidissement moteur (10) (en "g").
Reposer les vis (11).
Connecter le connecteur (9).
Accoupler le tube de dégazage (8).
ATTENTION : Retirer la protection sur le radiateur de refroidissement.
Reposer :
  • Le motoventilateur (7) (en "c") (par le dessous du véhicule)
  • Les vis (6)
Connecter les connecteurs :
  • Motoventilateur  (en "d")
  • Résistance motoventilateur (en "e")
  • Relais motoventilateur (en "b")
Reclipper le faisceau électrique .
Accoupler la durit (2) ( en "a").
Reposer :
  • Le raccord d’air (3)
  • Le résonateur d’air (4)
  • L’agrafe (5)
Positionner l’ensemble moteur-boîte de vitesses.
Reposer les vis (1).
Remplir et purger le circuit de refroidissement.
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie de servitude.
Rebrancher la batterie de servitude .
ATTENTION : Vérifier que le motoventilateur s’enclenche correctement.
