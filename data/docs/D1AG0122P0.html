D1AG0122P0Dépose - repose : Alternateur
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Débrancher la batterie de servitude.
Figure : b1bg146d
Déposer :
  • Le raccord (1) d’entrée boîtier papillon
  • Le raccord de sortie d’air (2) du turbocompresseur
  • Les vis (3) (selon équipement)
Soulever l’extrémité du pare-chocs.
Déclipper la fixation du refroidisseur d’air de suralimentation  (en "a").
Décaler l’ensemble refroidisseur d’air de suralimentation (Vers le moteur).
ATTENTION : Mettre en place des bouchons d’obturation sur les manchons de l’échangeur et du turbocompresseur .
Figure : d1ag01kd
Désaccoupler le tuyau de dégazage du circuit de refroidissement sur le radiateur moteur  (en "b").
Déposer les 2 raccords d’air (en "c").
ATTENTION : Obturer l’orifice du guide de jauge à huile ; À l’aide des bouchons .
Déposer :
  • La jauge à huile (4)
  • La vis (6)
  • Le guide de jauge à huile (5)
  • La vis (8)
  • Le support (7)
Déconnecter le connecteur en "d".
Figure : b1gg0f5d
Déposer :
  • Les vis (9)
  • Le motoventilateur (10) (vers le haut)
  • Le refroidisseur d’air de suralimentation (11) (vers le haut)
Figure : b1gg0f6d
Couper la lanière (en "e").
Déconnecter le connecteur "f" de l’alternateur .
IMPERATIF : Manipuler avec précaution le galet tendeur (15) en position pigée afin de ne pas le déverrouiller (risque de blessure).
Déposer :
  • La courroie d’entraînement des accessoires (14)
  • L’écrou (12) du câble d’alimentation de l’alternateur
  • Les vis (13)
  • Le galet tendeur (15)
Figure : d1ag01ld
Écarter le faisceau d’alimentation alternateur .
Déposer :
  • La vis (17)
  • L’alternateur (16) (Par le haut)
2. Repose
ATTENTION : Respecter les couples de serrage .
Contrôler la présence des bagues de centrage.
Reposer :
  • L’alternateur (16)
  • La vis (17)
  • Le galet tendeur (15)
  • Les vis (13)
  • L’écrou (12) du câble d’alimentation de l’alternateur (16)
Reconnecter le connecteur de l’alternateur (16) (en "f").

Reposer :

  • Le refroidisseur d’air de suralimentation (11)
  • Le motoventilateur (10)
  • Les vis (9)
  • Les 2 raccords d’air  (en "c")

Accoupler le tuyau de dégazage du circuit de refroidissement sur le radiateur moteur  (en "b").
