2. Opération préliminaire
Débrancher la batterie de servitude .

  • Le pare-chocs avant
  • Les feux de brouillard avant
  • Les feux diurnes (Suivant équipement)

4. Déshabillage
Déposer la plaque de police .
4.1. Déflecteurs de pare-chocs avant
Figure : c5jg06bd
Chasser les clous de rivets avant le perçage.
Percer les têtes de rivets (11) ; À l’aide d’un foret Ø 6 mm.
Déclipper les déflecteurs de pare-chocs avant (5) (en "a") ; À l’aide de l’outil [1350-ZZ].
Déposer les déflecteurs de pare-chocs avant (5).
Percer les corps de rivets restants.
4.2. L’absorbeur de chocs (/)
Figure : c5js01xd
Déclipper : L’absorbeur de chocs (1) (en "b") ; À l’aide de l’outil [1350-ZZ].
Déposer : L’absorbeur de chocs (1).
4.3. La grille de pare-chocs avant
Figure : c5js01yd
Araser les points de fixation de la grille  (en "d").
Déclipper : La grille de pare-chocs avant (9) (en "c") ; À l’aide de l’outil [1350-ZZ].
Déposer : La grille de pare-chocs avant (9).
Figure : c5js01zd
Déclipper et déposer : La trappe d’accès (6) ; À l’aide de l’outil [1350-ZZ].
Figure : c5js020d
Déclipper et déposer : Le bandeau central (7) ; À l’aide de l’outil [1350-ZZ].
4.4. L’emblème de la marque
Figure : c5js021d
Déclipper et déposer : L’emblème de la marque (8) ; À l’aide de l’outil [1350-ZZ].
4.5. Les supports de feu de brouillard
Figure : c5js022d
Araser les points de fixation  (en "h").
Déclipper : Les supports de feu de brouillard (3) (en "g") ; À l’aide de l’outil [1350-ZZ].
Déposer : Les supports de feu de brouillard (3).
4.6. Les supports de feu diurne (Suivant équipement)
Figure : c5js023d
Araser les points de fixation  (en "j").
Déclipper : Les supports de feu diurne (4) (en "k") ; À l’aide de l’outil [1350-ZZ].
Déposer : Les supports de feu diurne (4).
5. Habillage
Procéder dans l’ordre inverse des opérations de déshabillage.
IMPERATIF : Utiliser la mallette de réparation soudage plastique et bouterollage [2] (Voir catalogue équipement des marques).
Bouteroller les points de fixation arasés ; À l’aide de l’outil [2].
Reposer :
  • Les feux diurnes (Suivant équipement)
  • Les feux de brouillard avant
  • Le pare-chocs avant
Rebrancher la batterie de servitude .
Vérifier le fonctionnement des différents équipements.
