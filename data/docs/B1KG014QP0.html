IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
outil Référence Désignation
Figure : e5ab06it
 [0188-T] kit obturateurs HDI
Figure : e5ab08pt
 [4145-T] pince pour dépose des colliers "clic"
2. Dépose
IMPERATIF : Moteur chaud : Attendre au minimum une heure avant toute intervention sur la ligne d’échappement.
Lever et caler le véhicule roues pendantes.
Déposer la protection sous moteur  (selon équipement).
Figure : b1kg069d
Déconnecter le connecteur  (en "a").
Déposer la vis (1).
Dégrafer le support ("b").
Écarter le capteur de pression gaz d’échappement (2).
ATTENTION : Repérer l’emplacement des tuyaux (3) sur le capteur de pression gaz d’échappement (2).
Déposer les colliers "clic"  (en "c") ; À l’aide de l’outil [4145-T].
Désaccoupler les tuyaux (3) du capteur de pression différentielle des gaz d’échappement (2).
Obturer les tuyaux (3) ; À l’aide du kit obturateurs [0188-T].
Déposer le capteur de pression gaz d’échappement (2).
Figure : b1kg06ad
Écarter le faisceau électrique "e" du logement (en "d").
Déposer :
  • La vis (4)
  • La patte de fixation (6)
  • Le raccord (5) (Par le dessous du véhicule)
Figure : b1kg06bd
Déposer :
  • Le raccord (9)
  • Le tube de prise de pression (7) (amont)
  • Le tube de prise de pression (8) (aval)
Figure : b1kg06cd
Déposer les colliers "clic" (10) ; À l’aide de l’outil [4145-T].
ATTENTION : Repérer l’orientation et l’appariement des tuyaux (3) de prise de pression souples sur les tubes (7), (8) avant de les désaccoupler.
Désaccoupler les tuyaux souples (3) de prise de pression des tubes métalliques (7), (8) de prise de pression (Tubes métalliques).
Obturer les tubes de prise de pression et les conduits de prise de pression de l’ensemble précatalyseur/ filtre à particules ; À l’aide du kit obturateurs [0188-T].
3. Repose
ATTENTION : Respecter les couples de serrage .
ATTENTION : Remplacer les colliers "clic" déposés par des neufs.
Déposer les obturateurs [0188-T] des tubes de prise de pression et des conduits de prise de pression de l’ensemble précatalyseur/filtre à particules.
ATTENTION : Accoupler les tuyaux souples (3) de prise de pression sur les tubes (7), (8) dans l’orientation et l’appariement repérés lors de la dépose.
Reposer :
  • Les 2 colliers "clic" neufs (10) ; À l’aide de l’outil [4145-T]
  • Le tube de prise de pression (8) (aval)
  • Le tube de prise de pression (7) (amont)
Serrer les raccords (9) et (5).
Reposer :
  • La patte de fixation (6)
  • La vis (4)
  • Le faisceau électrique "e" (en "d")
Repositionner sans contrainte les tuyaux (3) sur le support "b" avant de les accoupler sur le capteur de pression (2) de gaz d’échappement.
Déposer les obturateurs [0188-T].
Accoupler les tuyaux (3) sur le capteur de pression (2) de gaz d’échappement suivant les emplacements repérés lors de la dépose.
Reposer :
  • Les 2 colliers "clic" neufs (en "c") ; À l’aide de l’outil [4145-T]
  • Le capteur de pression gaz d’échappement (2)
Agrafer le support "b".
Reposer la vis (1).
Reconnecter le connecteur  (en "a").
4. Contrôle
Démarrer le moteur.
Vérifier l’absence de fuite de gaz d’échappement.
Arrêter le moteur.
5. Opération complémentaire
Reposer la protection sous moteur  (selon équipement).
