3. Repose
3.1. Charnières de porte (Côté porte)
Figure : c4cg0owd
NOTA : Les charnières de portes (7) sont indexées côté porte ; Il est cependant possible de supprimer l’indexage si un réglage supplémentaire est nécessaire (en "c").
Déposer :
  • Les vis (8)
  • Les charnières de porte (7)
ATTENTION : Effectuer les traitements anticorrosion dans la zone des pions d’indexage .
Couper les pions d’indexage  (en "c") ; À l’aide d’une scie à métaux.
Reposer les charnières de porte (7) (sans serrer).
3.2. Charnières de porte (Côté caisse)
Figure : c4cg0oxd
ATTENTION : Effectuer les traitements anticorrosion dans la zone des pions d’indexage .
NOTA : Les charnières de portes sont indexées côté caisse Il est cependant possible de supprimer l’indexage (en "d") si besoin de réglage supplémentaire.
Déposer les charnières .
Supprimer l’indexage "d" (À l’aide d’un chasse-goupille).
Reposer les charnières  (sans serrer).
Le réglage des jeux de la porte avant s’effectue sur les charnières fixes maintenues par les vis (9).
3.3. Gâche de porte avant
Figure : c4cg0oyd
Desserrer d’un quart de tour les vis (10) pour permettre la fermeture de la porte sans contrainte par la gâche (11).
3.4. Réglage
Reposer :
  • La porte avant (1) ; À l’aide du support de porte
  • Les axes (5)
  • Les clips (2)
  • La vis (4) du tirant de porte (3)
Connecter les connecteurs  (en "b").
Régler les jeux et affleurements de la porte ; À l’aide des vis (8), (9), (10).
Approcher les vis (8), (9), (10) jusqu’au contact, sans serrer.
Déconnecter les connecteurs  (en "b").
Déposer :
  • Les clips (2)
  • Les axes (5) ; À l’aide de l’outil [1355-B]
  • La vis (4) du tirant de porte (3)
Dégager la porte avant (1) (Veiller à ne pas entrer en contact avec l’aile avant).
Serrer :
  • Les vis (8) à 3 m.daN
  • Les vis (9) à 3 m.daN
  • Les vis (10) à 2 m.daN
