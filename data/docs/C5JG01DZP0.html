IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Opérations préliminaires
Placer le véhicule sur un pont élévateur à 2 colonnes.
Déposer les roues avant.
Déposer les pare-boue avant .

  • Les vis (4) des fixations inférieures du pare-chocs avant

Déposer : Les écrous de fixation (6) du renfort (5) (Déflecteur de pare-chocs avant ) (Opération symétrique).
Déposer : Le renfort (5) (Déflecteur de pare-chocs avant ) (Opération symétrique).

Déposer :
  • L’agrafe (7) (Opération symétrique)
  • Les écrous (8) (Opération symétrique)

3. Dépose : Lame de déflecteur de pare-chocs avant
Figure : c5jg0x4d
Chasser les clous de rivets avant le perçage.
À l’aide d’un foret ø 4 mm, percer les rivets  (en "b").
Déposer les écrous  (en "c").
Dégager : La lame (10) (Déflecteur de pare-chocs avant (9)) (Suivant la flèche "d").
Déposer : La lame (10) (Déflecteur de pare-chocs avant (9)).
4. Repose
NOTA : Remplacer les écrous à chaque démontage. Remplacer systématiquement les agrafes défectueuses.
Procéder dans l’ordre inverse des opérations de dépose.
